# @deepseek-ai/dsh-client-ui-usage

[English](README.md) | 中文

浏览器插件，注册 **用量** 设置页：基于宿主 `usage` Remote 的移动响应式仪表盘。区块：余额卡（或不可用文案）、时间范围选择（今天/本周/本月/全部）、合计、按模型表、按日列表。中文为主文案；英文作为 locale 副本。

## 组合

以 `settings.section` 条目注册（`id: usage`，`order: 20`），待 ui-settings 声明该 slot。要求网关上存在 `usage` Remote（由 `@deepseek-ai/dsh-api-remotes` 挂载）。

侧栏底部显示今日估算费用、余额和充值链接；用量页面另有每日费用与模型占比图表。两处均使用应用主题已有的背景、边框和按钮变量。侧栏每分钟及窗口获得焦点时刷新。

## 模型体验

无——插件只渲染已计算的用量与余额值。

#### KV Cache 影响

无。

## 已知限制与延后工作

- **仅打开时拉取** — 范围变化或用户点重试时加载；无后台推送失效。
- **无独立 `/usage` 路由** — v1 作为设置页。后续顶级导航可复用同一组件。
